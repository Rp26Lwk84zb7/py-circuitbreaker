# Circuit breaker

```
circuit.py
```
Check the tests next to the implementation. That is where you will find concrete examples.

This is a minimal closed, open, and half-open circuit breaker. I injected the clock so you can test it properly. Zero external dependencies.

I wrote this using only the Python standard library. You do not need to install any extra packages. When you run a solo shop, every minute spent fixing dependency conflicts is a minute not spent shipping features. Keep your stack light.
